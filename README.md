# Campus App

Campus App on opiskelijoille suunniteltu tapahtumasovellus.

## Ominaisuudet

- Tulevien tapahtumien tarkastelu
- Tapahtumiin ilmoittautuminen
- Omien ilmoittautumisten tarkastelu
- Palautteen antaminen

## Projektin tarkoitus

Projektissa harjoitellaan ohjelmistokehityksen
tehtävien hallintaa Jiralla ja GitHubilla.
